User query
    -> classify_intent local
    -> nếu confidence cao và query đơn giản:
          parse_query_plan local
       nếu confidence thấp hoặc query phức tạp:
          gọi LLM parser
    -> validate_query_plan
    -> build_clip_queries
    -> search_clip_text





  - Giữ classify_intent chỉ để phân loại TEXTUAL_KIS / QA / TRAKE, gắn confidence, và làm hint cho Gemini.
  - Thêm planner orchestration:
      - plan_query(query) là entrypoint chính sau này thay cho gọi trực tiếp parse_query_plan.
      - Nếu Gemini bật và query phức tạp, gọi Gemini để tạo QueryPlan.
      - Nếu Gemini lỗi, thiếu key, timeout, JSON sai schema, fallback về local parse_query_plan.

  - Thêm Gemini parser:
      - Dùng google-genai.
      - Env dùng GEMINI_API_KEY, GEMINI_MODEL, USE_LLM_PARSER, LLM_PARSER_MODE.
      - Prompt yêu cầu Gemini trả đúng schema QueryPlan.
      - Kết quả luôn đi qua validate_query_plan, không dùng raw JSON trực tiếp.

  - Thêm complexity gate:
      - Gọi Gemini nếu intent.confidence thấp.
      - Gọi Gemini nếu query dài, có nhiều dấu phẩy, nhiều temporal connector, hoặc có nhiều entity/action khả nghi.
      - Không gọi Gemini cho query rất đơn giản nếu LLM_PARSER_MODE=auto.


        user query
    -> classify_intent(query)
    -> should_use_llm_parser(query, intent, config)
        -> nếu USE_LLM_PARSER=false
             dùng local parse_query_plan(query, intent)
        -> nếu USE_LLM_PARSER=true + LLM_PARSER_MODE=auto
             chỉ gọi Gemini nếu query phức tạp
        -> nếu USE_LLM_PARSER=true + LLM_PARSER_MODE=always
             luôn gọi Gemini
    -> Gemini parse nếu được bật và gate cho phép
        -> Gemini trả JSON QueryPlan
        -> validate_query_plan(...)
    -> nếu Gemini lỗi / thiếu key / JSON sai
        fallback local parse_query_plan(query, intent)
    -> QueryPlan hợp lệ
    -> build_clip_queries(plan)
    -> search_clip_text(...)






    Ví dụ khi deploy:

  USE_LLM_PARSER=false

  Hệ thống chạy local parser hoàn toàn:

  - không tốn API
  - chạy offline
  - dùng khi thiếu quota/key
  - dùng cho test/dev nhanh

  USE_LLM_PARSER=true
  LLM_PARSER_MODE=always

  Query nào cũng đi Gemini parser:

  - chất lượng bóc tách tốt hơn
  - tốn API hơn
  - latency cao hơn
  - phù hợp demo/chạy production nếu ưu tiên accuracy

  USE_LLM_PARSER=true
  LLM_PARSER_MODE=auto

  Chỉ query phức tạp mới đi Gemini parser:

  - cân bằng cost/quality
  - query đơn giản dùng local parser
  - query khó dùng LLM

  USE_LLM_PARSER=true
  LLM_PARSER_MODE=never

  Gần giống tắt parser, hữu ích nếu bạn muốn giữ biến bật nhưng ép route local trong một môi trường nào đó.
