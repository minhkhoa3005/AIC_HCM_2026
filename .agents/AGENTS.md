# Project Rules

- Không tự động cập nhật, commit hoặc push lên GitHub trừ khi được người dùng yêu cầu rõ ràng.
- Bất cứ khi nào chỉnh sửa mã nguồn (code) hoặc thay đổi kiến trúc, PHẢI kiểm tra và đồng bộ hóa các thay đổi đó trên tất cả các định dạng file liên quan bao gồm: `.md` (tài liệu), `.txt` (file văn bản), `.ipynb` (Jupyter notebooks), và `.py` (code Python), đồng thời phải áp dụng triệt để xuống tất cả các thư mục con (subdirectories) trong dự án để đảm bảo tính nhất quán.
